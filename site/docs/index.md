# Orion guides

Orion is a local workspace for organising personal media, with a standalone Windows bundle and a cross-platform Python source runtime. It scans folders you choose, helps you identify items, and shows the exact proposed paths before you approve file operations. It supports movies, TV series, anime, anime films, web series, music and books.

The sample organiser on the [Orion home page](../) uses fictional fixture data. It does not inspect your computer, connect to the installed app, or move files. To use your own library, install Orion and run it locally.
