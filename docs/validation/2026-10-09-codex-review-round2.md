# Codex review corrections, second pass — 9 October 2026

The eleven findings in the second Codex review of PR #3 were checked against the runtime and reproduced with regressions. The first backend run reported 22 failures and two passing controls; the disabled-key and missing-recovery-warning UI tests failed. Further regressions reproduced the direct AniDB transport error, mismatched displayed provider defaults and missing recovery-path display before correction.

| Review comment | Implemented correction | Verification |
| --- | --- | --- |
| [Vanished directory media](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053194) | Items not rediscovered inside a fully scanned source become unavailable even if their directory still exists. Paths moved outside that source remain indexed as organised. | Shallow/deep scans of subtitle-only directories; media return invalidates an obsolete decision; rescanning an organised source preserves destination identity. |
| [Filesystem-root overlap](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053202) | Compare normalized paths using relative containment rather than concatenating separators. | Registering a drive/filesystem root and its descendant is rejected in either order. No files outside test roots are scanned or modified. |
| [Provider-test transport errors](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053206) | Normalize request exceptions into safe provider errors, including AniDB's direct catalogue request; record unavailable health instead of retaining a stale success. | Timeout, connection failure, HTTP 401/403/503 and AniDB timeout fixtures verify health/job error codes without exposing request secrets. |
| [Stored category provider](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053214) | Lookup, category display and settings display share the same provider selection. Explicit lookup overrides take priority, followed by saved JSON preferences, stored category choices and a fallback. Imported categories precede seeded defaults when categories share a kind. | Fresh and migrated startup, duplicated imported/default kinds and later preference/explicit overrides show and invoke consistent providers. Reads are outside the category writer transaction to avoid nested SQLite writer locking. |
| [Video in nonvideo sources](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053226) | Skip video extensions in sources explicitly configured as music or books. | Mixed audio/video and book/video directories index only the supported configured media. |
| [Filename extensions](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053228) | Exact filename overrides must preserve the original suffix, compared case-insensitively. | Different and missing suffixes fail before planning; matching suffixes with different casing remain accepted. |
| [Linked source ancestors](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053233) | Reject a configured source when any ancestor is a symbolic link or Windows junction. | A real Windows junction/POSIX symlink with an ordinary child directory is rejected before source registration. |
| [Undo residual directory members](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053242) | Preserve unrecorded files, retain error/split-location metadata, persist a partial batch result with affected item IDs, and display both recovery locations. Retrying after the residual files are handled clears recovery metadata. | Real media/subtitle undo leaves a user-added file intact, reports partial restoration and shows both paths; safe retry restores complete state. The browser exercises the same flow with 256 MiB of generated media and NFO. |
| [Queued cancellation](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053248) | Keep queued cancellations in cancelling until the worker removes the scheduler entry and atomically publishes cancelled. | Occupied writer and three occupied reader slots: queued service never runs after cancellation, premature retry is rejected and terminal cancellation is immediately retryable. |
| [Disabled server credential clearing](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053258) | Allow the idempotent clear action whenever the form is idle, regardless of integration configuration. | UI sends DELETE with disabled/empty server settings; production browser confirms the action remains enabled and succeeds. |
| [Undo audit action](https://github.com/Varun-SV/Orion/pull/3#discussion_r4229053267) | Record undo batches under undo and include the original batch ID. | Forward/restoration audit entries are distinct and retain their batch relationship; production browser verifies the record. |
